## 📋 Loyiha Haqida

Sayt bitta sahifali (One Page / SPA uslubida) portfolio bo'lib, quyidagi maqsadlarda yaratilgan:

- Frontend dasturchining ko'nikmalari va tajribasini namoyish etish
- Bajarilgan loyihalarni (portfolio) ko'rsatish
- Potensial mijozlar yoki ish beruvchilar bilan bog'lanish imkonini yaratish
